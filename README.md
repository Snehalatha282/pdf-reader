# PDF Reader

A simple PDF-based question-answering application that allows users to upload a PDF and ask questions based on its content.

## Features

* 📄 **PDF Upload**
  Upload an academic or text-based PDF document.

* 🔍 **PDF Content Analysis**
  Extract and process the content available in the uploaded PDF.

* 💬 **Question Answering**
  Ask questions related to the uploaded PDF.

* 🧠 **Content-Based Answers**
  Generate answers based on the information available in the uploaded document.

* 🖥️ **Simple Web Interface**
  Interactive interface built using Streamlit.

## Technologies Used

* Python
* Streamlit
* PDF Processing
* NLP / Question Answering

## Installation

```bash
git clone https://github.com/Snehalatha282/pdf-reader.git
cd pdf-reader
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

The application will open in your web browser.

## Usage

1. Upload a PDF.
2. Wait for the document to be processed.
3. Enter your question.
4. Get an answer based on the uploaded PDF.
